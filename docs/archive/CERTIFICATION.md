# WebWeaveX Certification

Nothing in WebWeaveX is "certified" because a report says so. Every
certification is **regenerated by execution**, and every artifact carries its
reproduction commands, commit hashes, and SHA-256s of the outputs.

Current verdict: **PASS** — see `final_certification.json` (committed at the
repo root of the `dart` branch and mirrored in
`validation/zero_trust_v2/`).

## The certification model

| Certification | What it proves | Harness | Scale |
|---|---|---|---|
| Core determinism | byte-identical stable-serialize / canonical JSON / SHA-256 / Kaalka encrypt / fingerprint, 3 runs per language | `cross_language_verifier/{generate_vectors.py, run_*.{py,mjs,dart}, compare.py}` | 10,000 vectors × 6 fields × 3 langs × 3 runs |
| Extraction | `extract_semantic_html` / `extract_semantic_content` parity | `cross_language_verifier/{gen_synth_html.py, synth_*, extract_*}` | 10,000 synthetic + 1,006 real pages + 14 torture |
| Semantic IR | ~300 engine functions, layers A–O + parsers + repository + application closures | `validation/semantic_ir/{run_*.{py,mjs,dart}, compare_results.py}` | 667 fixtures, hash + deep equality |
| Executable API | runtime-cognition public APIs | `validation/executable/` | 35 fixtures |
| Million-vector | aggregate digest equality across 5 IR families | `validation/zero_trust_v2/mv_*.{py,mjs,dart}` | 1,000,000 vectors |
| Determinism audit | no uncontrolled time/random/locale/platform in the portable surface | `validation/zero_trust_v2/determinism_scan.py` | static + executed |
| Performance | throughput benchmarks + no blow-up at scale | `cross_language_verifier/bench_*.{py,mjs,dart}` | measured ops/s |
| Security | no exec/eval, bounded network, parser-abuse survival | audit + the torture corpora | executed |

## Reproducing everything

Materialize the three implementations (any one repo contains all three as
branches):

```bash
git clone <repo> wwx && cd wwx
git worktree add ../wwx-py python
git worktree add ../wwx-js javascript     # then: cd ../wwx-js && npm install
# dart branch is this checkout:           dart pub get
```

Then, per certification (commands also embedded in each JSON artifact):

```bash
# semantic IR (the big one)
cd validation/semantic_ir
PYTHONPATH=../../../wwx-py python run_python.py fixtures.json > python_results.json
cp run_js.mjs ../../../wwx-js/ && (cd ../../../wwx-js && npx tsx run_js.mjs <abs>/fixtures.json > <abs>/js_results.json)
dart run validation/semantic_ir/run_dart.dart validation/semantic_ir/fixtures.json > validation/semantic_ir/dart_results.json
python compare_results.py        # expect: 667/667
```

The real-page corpus is not committed (size); regenerate it with
`cross_language_verifier/fetch_corpus.py` against
`cross_language_verifier/corpus/manifest.json` (URL + SHA-256 per page).

## Certified contracts and boundaries

1. **v2 numeric canonicalization** — integral floats serialize as integers in
   all three languages (see ARCHITECTURE.md).
2. **AST contract** — valid-Python native-AST enrichment is Python-only by
   design; the 3-way parity domain for parser paths is non-Python sources,
   invalid Python, and the `parse_python_ast` scanner envelope.
3. **Partial/Deferred APIs** — network-gated and platform-bound APIs are
   classification boundaries documented in `PARTIAL_API_AUDIT` /
   `DEFERRED_API_AUDIT` sections of `PARITY_MANIFEST.json`; their
   deterministic sub-paths are certified, their live side effects are not
   claimed.

## Adding to the certified surface

1. Port the engine (Python is canonical; match it bit-exactly — see
   AI_AGENT_GUIDE.md for the pitfalls catalogue).
2. Add fixtures via a `gen_*_fixtures.py` provenance script.
3. Wire the three harness registries.
4. Execute 3-way; require hash + deep equality.
5. Freeze executed-Python outputs as vectors under `validation/parity/` and
   add the suite test.
6. Regenerate `PARITY_MANIFEST.json` and the matrix.

Never mark anything Complete without a 3-way executed proof. Never trust a
historical report — re-run it.
