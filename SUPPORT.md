# Support

Thanks for using WebWeaveX — deterministic runtime cognition infrastructure for humans and AI agents.

## Getting help

| Need | Where |
|------|-------|
| Bug reports / feature requests | [GitHub Issues](https://github.com/ni-sh-a-char/WebWeaveX/issues) |
| Questions / discussion | Open an issue with the `question` label |
| Documentation | [README](README.md), [`docs/`](docs/), [`PUBLIC_API_MATRIX.md`](PUBLIC_API_MATRIX.md) |
| Security vulnerabilities | **Do not** open a public issue — follow [SECURITY.md](SECURITY.md) |

## Before filing an issue

1. Confirm you are on the `dart` branch and Dart SDK `>=3.3.0`.
2. Run `dart pub get` and the gate sequence in [CONTRIBUTING.md](CONTRIBUTING.md).
3. Include: Dart version, OS, a minimal reproduction, and expected vs actual output.

## Scope

WebWeaveX is a deterministic runtime library. Questions about live-browser automation, native
OS automation, or NLP/AST compilation may fall under **Deferred** capabilities — see
[`API_PARITY_VALIDATION_REPORT.md`](API_PARITY_VALIDATION_REPORT.md) for what is in-scope for Dart.
