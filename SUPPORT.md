# Support

## Getting Help

- **Documentation**: See the [README](README.md) for quick start and API reference
- **Issues**: [GitHub Issues](https://github.com/ni-sh-a-char/WebWeaveX/issues) for bugs and feature requests
- **Discussions**: [GitHub Discussions](https://github.com/ni-sh-a-char/WebWeaveX/discussions) for questions

## Reporting Issues

Please use GitHub Issues to report bugs. Include:
- Kotlin version
- JVM version
- OS
- Minimal reproduction code
- Expected vs actual behavior
