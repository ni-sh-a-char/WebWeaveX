### Why `validation/` and `cross_language_verifier/` were safe to remove

The Java parity proof is **self-contained** and does not reference either tree:

- Golden vectors: `java/src/test/resources/parity/golden_vectors{,_s2,_s3}.json`,
  generated by `tools/gen_java_parity_vectors*.py` from the canonical Python `core`.
- Assertions: `io.webweavex.parity.CrossLanguageParity*Test` (run by `mvn verify`).
- Governance: `tools/validate_java_manifest.py` over `PARITY_MANIFEST.json` +
  `java/JAVA_PARITY_MATRIX.md` + the Java golden vectors.

`grep` for imports/reads of `validation/` or `cross_language_verifier/` in the Java
tooling and the Maven project returns nothing. The two trees belong to the earlier
multi-language certification effort and survive on the `python`/`dart`/`javascript`
branches.

## Recovery

Any removed file is recoverable:

```bash
git checkout dart    -- lib/ test/ pubspec.yaml          # Dart artifacts
git checkout python  -- <path>                           # Python artifacts
git log --diff-filter=D --name-only -- <path>            # locate the deleting commit
```
