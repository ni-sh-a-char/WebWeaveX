# WebWeaveX Language Implementations

WebWeaveX is **deterministic runtime cognition infrastructure for humans and AI agents**, implemented **natively per language** on isolated ecosystem branches.

| Branch | Ecosystem Purpose | Native Package | Version Status | Supported Surfaces |
|:---|:---|:---|:---|:---|
| [`main`](https://github.com/ni-sh-a-char/WebWeaveX) | Language-neutral architecture & ecosystem portal | — | Active Portal | Ecosystem Specification |
| [`python`](https://github.com/ni-sh-a-char/WebWeaveX/tree/python) | Production-grade Python runtime | [PyPI `webweavex`](https://pypi.org/project/webweavex/) | **Stable (v3.0.0)** | Web, Native, Repo, Connectors |
| [`javascript`](https://github.com/ni-sh-a-char/WebWeaveX/tree/javascript) | Production-grade Node/TypeScript runtime | [npm `webweavex`](https://www.npmjs.com/package/webweavex) | **Stable (v3.0.0)** | Web, Node.js, Browser AI |
| [`dart`](https://github.com/ni-sh-a-char/WebWeaveX/tree/dart) | Production-grade Flutter/Dart runtime | [pub.dev `webweavex`](https://pub.dev/packages/webweavex) | **Stable (v3.0.0)** | Web, Flutter, Mobile |
| [`java`](https://github.com/ni-sh-a-char/WebWeaveX/tree/java) | Production-grade Enterprise Java runtime | [Maven `io.webweavex:webweavex`](https://search.maven.org/artifact/io.webweavex/webweavex) | **Stable (v3.0.0)** | Enterprise JVM, Web, Connectors |
| [`kotlin`](https://github.com/ni-sh-a-char/WebWeaveX/tree/kotlin) | Production-grade Native Kotlin runtime | [Maven `io.webweavex:webweavex-kotlin`](https://search.maven.org/artifact/io.webweavex/webweavex-kotlin) | **Stable (v3.0.0)** | Android, KMP, Coroutines |
| `rust` | Performance extraction workers (planned) | `webweavex-rs` | Planned | Rust Worker Engines |
| `go` | Sidecar deployment agents (planned) | `webweavex-go` | Planned | Go Deployment Sidecars |

| Architecture, security, parity specs, ecosystem vision | [`main`](https://github.com/ni-sh-a-char/WebWeaveX) | GitHub Ecosystem Portal |

## Shared Pillars Across All Implementations

1. Universal Runtime Cognition  
2. Deterministic Serialization & Normalization  
3. Replay Equivalence & Graph Matching  
4. Bounded Reconstruction  
5. Federated Memory Fabric  
6. Allowlisted Execution Sandbox  
7. Authenticated Continuation (Authorized Sessions Only)  
8. Cross-Language Parity ([`kaalka@5.0.0`](https://www.npmjs.com/package/kaalka) Cryptographic Specification)  
9. Stable Graph Identity & SHA-256 Hashes
