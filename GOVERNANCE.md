# WebWeaveX Governance

WebWeaveX is **deterministic runtime cognition infrastructure** for humans and AI agents.

## Canonical branch

- **Python** (`origin/python`) is the canonical runtime and specification source.
- **JavaScript** (`javascript`) converges to Python via forensic audits and differential validation.

## Decision process

1. Changes that affect cross-language contracts require parity vector updates.
2. Releases require passing ecosystem validation on the target branch.
3. Security issues follow [SECURITY.md](SECURITY.md).
