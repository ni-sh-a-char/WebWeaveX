# Governance

## Decision Making

WebWeaveX follows a meritocratic governance model:

- **Maintainers** review and merge pull requests
- **Contributors** submit issues and pull requests
- **Community** provides feedback and testing

## Release Process

See [RELEASE.md](RELEASE.md) for the release process.

## Versioning

Follows Semantic Versioning (MAJOR.MINOR.PATCH).
All SDKs share the same version number.
