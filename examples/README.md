# Examples

Runnable scripts (require `pip install -e ".[browser]"` for Playwright paths).

| Script | Description |
|--------|-------------|
| [browser_extraction.py](browser_extraction.py) | Public URL extraction |
| [authenticated_extraction.py](authenticated_extraction.py) | Encrypted session continuation (authorized runtime) |
| [repository_cognition.py](repository_cognition.py) | Repository IR from a local path |
| [runtime_reconstruction.py](runtime_reconstruction.py) | Reconstruction from extraction sources |

```bash
python examples/browser_extraction.py
```
